## Установка World of Tanks на смартфон



Установка игры, известной теперь как **Tanks Blitz** (ранее World of Tanks Blitz), на смартфон производится через официальные магазины приложений. Для Android: Google Play,  RuStore, AppGallery. Для iOS: App Store. Нужно найти «Tanks Blitz»,  нажать «Установить» и дождаться загрузки игровых файлов. 

**Подробная инструкция:**

1. **Android:**
   - Откройте Google Play или RuStore.
   - Введите в поиске «Tanks Blitz».
   - Нажмите «Установить».
   - Запустите приложение для докачки необходимых игровых ресурсов.
2. **iOS (iPhone/iPad):**
   - Откройте App Store.
   - Найдите «Tanks Blitz» и скачайте.
3. **Альтернативный способ (Android):**
   - Скачать APK-файл с официального сайта, разрешив установку из неизвестных источников в настройках. 



Убедитесь, что на телефоне достаточно места для игры. На территории РФ для  скачивания лучше использовать RuStore или другие поддерживаемые  магазины. 



## Установка World of Tanks на ПК 

### Предварительная проверка

**Системные требования:** перед установкой убедитесь, что ваш компьютер соответствует минимальным требованиям системы.

**Свободное место на диске:** необходимо проверить наличие достаточного объема памяти:

- Для HD-версии: **81 ГБ** для самой игры + **27 ГБ** для обновлений
- Для SD-версии: **53 ГБ** для игры + **17 ГБ** для обновлений

### Процесс установки

1. **Загрузка Game Center:**

- Скачайте официальный лаунчер Game Center с официального сайта https://lesta.ru/support/ru/products/lgc/article/23738/
- Установите Game Center на компьютер

1. **Авторизация:**

- Запустите Game Center
- Войдите в свой аккаунт или создайте новый

1. **Выбор параметров установки:**

- В разделе «Все игры» найдите World of Tanks
- Нажмите на игру для открытия окна установки
- Выберите необходимые параметры:
  - Регион
  - Язык игры
  - Тип клиента (SD или HD)
  - Папку для установки
  - Опцию автоматических обновлений

1. **Запуск установки:**

- Проверьте указанный объем свободного места
- Нажмите «Принять и Установить»
- Дождитесь завершения процесса установки

### Важные примечания

- **Управление установкой:** вы можете приостановить процесс установки в любой момент и продолжить его позже
- **Автоматические обновления:** при запуске игры через Game Center будут устанавливаться необходимые обновления
- **Запуск игры:** после завершения установки появится кнопка «Играть»

Если во время установки возникнут проблемы, рекомендуется:

- Проверить подключение к интернету
- Убедиться в наличии прав администратора
- Проверить целостность файлов установки
- Обратиться в службу поддержки, если проблема не решается
