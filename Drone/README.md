## Drone

Для тренировки навыков управления дронами (особенно FPV) существует целый ряд симуляторов, которые позволяют оттачивать технику без риска разбить дорогостоящее оборудование. 

Лучшими симуляторами являются **Liftoff**, **Uncrashed**, **Velocidrone** и **DRL Simulator**. Они предлагают реалистичную физику, настройку квадрокоптеров и подходят для обучения новичков и тренировок профи. Для мобильных устройств  подойдут **FPV Freerider** или **World of Drones**. 



### Лучшие симуляторы для ПК (FPV/Дрон-рейсинг)



**Для профи и физики:**

- **Velocidrone** — лидер по точности физики. Его выбирают те, кому важно, чтобы дрон в игре ощущался ровно так же, как в жизни.
- **The Drone Racing League (DRL)** — лучший выбор для киберспорта. Позволяет летать по огромным детализированным трассам из реальных чемпионатов.



**Для кастомизации и графики:**

- **Liftoff: FPV Drone Racing** — «золотой стандарт». Самое большое сообщество, сотни запчастей и возможность собрать свой уникальный дрон.
- **Uncrashed: FPV Drone Simulator** — самый красивый симулятор на сегодня. Идеален для отработки кинематографичных съемок и фристайла.



**Для новичков и слабых ПК:**

- **FPV Freerider** — классика. Очень легкий, запускается на любом «калькуляторе», отлично подходит для первых шагов.
- **FPV Air 2** — бюджетный и простой в освоении вариант с неплохой физикой.
- **FPV SkyDive** — лучший **бесплатный** вариант в Steam, чтобы попробовать полеты, не тратя деньги.



Специализированные и российские проекты

- **Квадросим** — реалистичный симулятор для подготовки операторов БПЛА, включающий режимы «Спорт», «VR» и специальные сценарии для обучения.
- **Академия дронов** — образовательный симулятор в Steam с поддержкой русского языка, предлагающий различные тренировочные трассы. 



Мобильные приложения (Android/iOS)

- **FPV SkyDive** — мобильная версия популярного симулятора.
- **Drone Simulator Realistic UAV** — приложение с упором на реалистичное поведение дрона.
- **FPV War Kamikaze Drone** — симулятор, имитирующий выполнение боевых задач. 



**Совет для новичков**: для максимально эффективной тренировки рекомендуется подключать к  компьютеру настоящий пульт управления (аппаратуру) через USB. Это  позволит развить правильную мышечную память, которая пригодится при  переходе на реальный дрон.

## Бюджетная аппаратура (пульты)

Для симуляторов лучше всего подходят пульты с поддержкой протокола **ELRS** (ExpressLRS) и подключением по USB.

- **Radiomaster Pocket (ELRS)**
  - **Особенности:** Самый популярный компактный пульт. Имеет съемные стики и складную антенну, что удобно для переноски.
  - **Для кого:** Идеально для новичков, которым нужен качественный, но недорогой вход в хобби.
- **Radiomaster Boxer (ELRS)**
  - **Особенности:** Полноразмерный пульт с мощным передатчиком. Считается «золотым  стандартом» для тех, кто планирует летать не только в симуляторе, но и  на реальных дронах.
- **BETAFPV LiteRadio 3 (ELRS)**
  - **Особенности:** Очень бюджетный вариант, по форме напоминает геймпад. Поддерживает простую калибровку стиков через кнопку SETUP.
- **FlySky FS-i6X**
  - **Особенности:** Классический бюджетный пульт. Для симулятора потребуется специальный USB-адаптер (симуляторный кабель). 



## Настройка рейтов (Rates) для плавного старта

Рейты определяют, насколько быстро дрон будет вращаться при отклонении стика. Новичкам рекомендуется устанавливать **низкие значения**, чтобы управление было предсказуемым.

- **Максимальная скорость (Max Rate):** Начните с **400–500 град/сек**. На таких настройках дрон не будет резко «дергаться» при малейшем касании.
- **Экспонента (Expo):** Установите значение в районе **0.15–0.25**. Это сделает стики менее чувствительными в центре, что поможет точнее удерживать дрон при зависании.
- **Угол камеры:** В настройках симулятора выставьте угол **10°–15°**. Низкий угол камеры не дает дрону слишком сильно разгоняться, что критично для первых часов обучения. 



## Список базовых упражнений

Рекомендуется набрать минимум **10 часов** в симуляторе, прежде чем пробовать фигуры пилотажа. 

1. **Зависание (Hovering):** Удерживайте дрон в одной точке на уровне глаз в течение 20-30 секунд. Это база для контроля газа (Throttle).
2. **Квадрат:** Пролетите по периметру воображаемого квадрата, всегда удерживая «нос» дрона направленным вперед.
3. **Восьмерка:** Самое важное упражнение. Летайте по траектории цифры «8», координируя  повороты левым (Yaw) и правым (Roll) стиками одновременно.
4. **Пролет через ворота:** Найдите на карте широкие арки или ворота. Старайтесь пролетать их на постоянной высоте без резких рывков.
5. **Орбита:** Выберите объект (например, дерево) и облетайте его по кругу, постоянно удерживая объект в центре камеры. 



**Совет**: Не переходите к флипам и роллам, пока не научитесь уверенно делать «восьмерку» и приземляться точно в выбранную точку.
