Разберу основные HTML‑теги для новичков — сгруппировал их по назначению и добавил краткие пояснения.

## 1. Базовая структура документа

Эти теги формируют «скелет» любой веб‑страницы:

- `<!DOCTYPE html>` — объявление типа документа (для HTML5).
- `<html>` — корневой элемент, обёртка всего документа.
- `<head>` — содержит метаданные (информация для браузера и поисковых систем).
- `<title>` — заголовок страницы (отображается во вкладке браузера).
- `<meta>` — метаинформация, например кодировка (charset="UTF-8") и настройки viewport.
- `<body>` — тело документа, содержит весь видимый контент.

**Пример минимального документа:**

html

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя первая страница</title>
</head>
<body>
  <!-- Здесь размещается контент -->
</body>
</html>
```

## 2. Текстовые теги

- `<h1>`–`<h6>` — заголовки разных уровней (`<h1>` — самый важный, обычно один на странице; `<h6>` — наименее важный).
- <p> — абзац текста.
- `<br>` — перенос строки (одиночный тег, не требует закрытия).
- `<hr>` — горизонтальная линия‑разделитель.
- `<strong>` или `<b>` — жирный текст (`<strong>` несёт семантическую нагрузку — важность, `<b>` — чисто визуальное выделение).
- `<em>` или `<i>` — курсив (`<em>` — акцент, `<i>` — визуальное выделение).
- `<mark>` — текст, выделенный маркером (жёлтым фоном).
- `<del>` или `<s>` — зачёркнутый текст.
- `<ins>` — подчёркнутый текст (вставка).
- `<sub>` — подстрочный текст (индекс внизу).
- `<sup>` — надстрочный текст (индекс вверху).
- <code> — фрагмент кода (моноширинный шрифт).
- <pre> — предварительно форматированный текст (сохраняет пробелы и переносы).

## 3. Списки

- `<ul>` — маркированный (неупорядоченный) список.
- `<ol>` — нумерованный (упорядоченный) список.
- `<li>` — элемент списка (используется внутри `<ul>` или `<ol>`).
- `<dl>` — список определений.
- `<dt>` — термин в списке определений.
- `<dd>` — определение термина.

## 4. Ссылки и навигация

- <a> — гиперссылка. Обязательный атрибут: href (адрес ссылки). Пример: <a href="https://example.com">Перейти на Example</a>.

## 5. Изображения и медиа

- <img> — вставка изображения. Обязательные атрибуты: src (путь к файлу) и alt (альтернативный текст). Пример: <img src="photo.jpg" alt="Описание фото">.
- <video> — вставка видео. Атрибуты: src, controls (панель управления).
- <audio> — вставка аудио. Атрибуты: src, controls.

## 6. Структурные (семантические) теги HTML5

Помогают браузерам и поисковикам лучше понимать структуру страницы:

- `<header>` — шапка сайта или раздела.
- `<nav>` — навигационное меню.
- `<main>` — основное содержимое страницы.
- `<article>` — самостоятельный блок контента (статья, новость).
- `<section>` — тематический раздел.
- `<aside>` — боковая панель, дополнительная информация.
- `<footer>` — подвал сайта или раздела.
- <figure> и <figcaption> — иллюстрация с подписью.

## 7. Формы

Для создания интерактивных элементов:

- `<form>` — форма для ввода данных.
- `<input>` — поле ввода (текст, email, пароль и т. д.).
- `<label>` — метка для элемента формы.
- `<button>` — кнопка.
- `<select>` и `<option>` — выпадающий список.
- `<textarea>` — многострочное поле ввода.

------

**Важные нюансы для новичков:**

- **Парные и одиночные теги.** Большинство тегов парные: `<p>Текст</p>`. Но есть одиночные, которые не требуют закрытия: `<img>`, `<br>`, `<hr>`.
- **Атрибуты.** Добавляют тегам дополнительные свойства. Записываются внутри открывающего тега: `<тег атрибут="значение">`. Самые частые: `id`, `class`, `style`, `title`, `src`, `href`, `alt`.
- **Иерархия заголовков.** Соблюдайте логическую структуру: после `<h2>` должен идти `<h3>`, а не `<h4>`.
- **Семантика.** Используйте теги по назначению: `<h1>` для заголовка, а не для увеличения шрифта; `<button>` для кнопок, а не `<div>`. Это улучшает доступность и SEO.
