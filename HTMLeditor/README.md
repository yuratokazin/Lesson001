Эта программа совмещает в себе редактор кода и бракзер

Слева находится редактор кода, а справа отображается результат выполнения кода

Как работает Интернет?

Сначала код в файле index.html сохраняется на другом компьюторе, а затем через браузер мы открываем его у себя на смартфоне

Браузер - это программа в которой мы видим результат выполнения кода

Редактор кода - это программа в которой мы пишем и сохранякм код
