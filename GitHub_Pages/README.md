# GitHub Pages 



Узнайте, как создать веб-сайт непосредственно из репозитория на GitHub. Изучите  Jekyll или другие средства для создания веб-сайтов и устраните неполадки с вашим сайтом GitHub Pages.

Настройка источника GitHub Pages осуществляется через вкладку «Settings»  (Настройки) репозитория -> «Pages». В разделе «Build and deployment»  выберите «Deploy from a branch», укажите ветку (например,`main` или `gh-pages`) и папку (`/` или `/docs`), затем нажмите «Save». После этого изменения публикуются при каждом `push` в выбранную ветку GitHub Docs. 



**Основные шаги настройки:**

1. **Переход в настройки:** На GitHub перейдите на страницу репозитория и нажмите вкладку **Settings** (Настройки).
2. **Раздел Pages:** В боковой панели в разделе «Code and automation» выберите **Pages**.
3. **Источник (Source):** В подразделе «Build and deployment» (Сборка и развертывание) выберите **«Deploy from a branch»** (Развернуть из ветки).
4. **Выбор ветки:** В разделе «Branch» выберите нужную ветку (обычно `main` или `master`) и папку (обычно `/root` или `/docs`), затем нажмите **Save**.
5. **Публикация:** После настройки, при отправке (push) изменений в выбранную ветку, сайт автоматически пересобирается. 



**Важные примечания:**

- Можно использовать GitHub Actions для более сложной настройки публикации.
- Ограничения включают размер сайта до 1 ГБ, 10 минут на сборку и 100 ГБ трафика в месяц.
- Сайт доступен, если репозиторий публичный (на бесплатном тарифе) или приватный (на платном).
